


## 项目概述







一个基于 **Flask**框架构建的轻量级自建博客平台。它支持文章的在线发布、编辑、删除以及自定义排序，并提供简洁炫酷的前端界面与动态特效。后端采用







Python 编写，前端结合 HTML/CSS/JavaScript







实现动态星空背景、菜单动画和开场光效。















------------------------------------------------------------------------















## 后端架构与关键技术















### 1. Flask 框架















-   以 `@app.route` 装饰器定义路由，例如 `@app.route('/')`







    负责首页展示、`@app.route('/login', methods=['GET', 'POST'])`







    处理用户登录请求。\







-   通过 `render_template` 渲染 Jinja2







    模板，将后端数据（如文章列表）传递给前端页面。















### 2. Markdown 文章处理















-   博客文章全部以 **Markdown 文件**存储在 `content` 目录。\







-   使用 `markdown` 第三方库在后端将 `.md` 文件转换为







    HTML，再通过模板动态输出到前端，实现图文混排与代码高亮。















### 3. 文章自定义排序















-   引入 `order.json` 作为顺序配置文件。\







-   后端在首页读取该文件并利用 `articles.sort(key=lambda x: …)`







    实现**手动排序**，保证前台展示顺序与后台拖拽一致。















### 4. 后台管理功能















-   采用 `@app.route('/admin')` 提供管理界面，列出全部 Markdown 文件。\







-   通过 `@app.route('/edit', methods=['GET', 'POST'])`







    实现新增/编辑文章，`@app.route('/delete/<filename>')`







    提供删除接口。\







-   使用 **session** 保存登录状态，并在需要权限的路由中检测







    `session.get('logged_in')` 进行访问控制。















### 5. 安全与配置















-   使用 `app.secret_key` 保护 session。\







-   仅在开发环境下运行 `debug=True`，实际部署可配合 WSGI 服务器。

## 前端实现与视觉效果















### 1. 动态星空背景















-   通过 `<canvas>` 与 JavaScript 绘制 3D







    深度感的星空，`requestAnimationFrame`







    循环更新星点位置，实现空间穿越般的视觉冲击。















### 2. 光幕揭示动画















-   使用 CSS `clip-path` 和 `transform` 配合







    `transition`，在页面加载时呈现"双光束从两侧向中线收缩"的开场效果，带来科幻感。















### 3. 响应式菜单与动画















-   顶部导航条采用 CSS `clip-path` 打造多边形按钮，鼠标悬停时通过







    `transform: scale` 放大并伴随霓虹光晕（`text-shadow`）呼吸动画。\







-   利用 `flex` 布局与媒体查询保证在不同屏幕下菜单自适应。















### 4. 后台页面交互















-   `admin.html` 通过原生 JavaScript







    实现**拖拽排序**：用户可直接拖动文章条目改变顺序，异步提交到







    `/save_order` 接口并写入 `order.json`，无需刷新页面。

## 总结











- **后端**：Flask 路由与装饰器管理访问逻辑，Markdown







转换、文件增删改查、Session 权限控制一应俱全。\







- **前端**：HTML 模板配合 CSS3 动画与 JavaScript







动态绘图实现效果。
